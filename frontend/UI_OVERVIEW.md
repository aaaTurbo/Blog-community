## 🎯 Функциональные особенности

### Система реакций
- **6 типов реакций:** 👍 like, ❤️ love, 😂 haha, 😮 wow, 😢 sad, 😠 angry
- **Счетчики:** отображают количество реакций
- **Взаимодействие:** клик на реакцию добавляет/удаляет ее
- **Активная реакция:** подсвечивается цветом при наличии

### Комментарии
- **Добавление:** форма для нового комментария
- **Список:** все комментарии с информацией об авторе
- **Реакции:** каждый комментарий может иметь реакции
- **Раскрытие:** секция комментариев раскрывается по клику

### Навигация
- **Боковое меню (Sheet):** быстрая навигация по страницам
- **Ссылки:** навигация через React Router
- **Защита:** ProtectedLayout проверяет аутентификацию
- **Выход:** кнопка logout в сайдбаре

### Тема
- **Toggle:** в сайдбаре есть переключатель темы
- **Сохранение:** выбранная тема сохраняется в localStorage
- **Синхронизация:** все компоненты используют одну тему

## 🚀 Как начать

1. **Dev сервер:**
   ```bash
   npm run dev
   ```

2. **Сборка:**
   ```bash
   npm run build
   ```

3. **Файлы для изучения:**
   - `src/pages/FeedPage.tsx` - пример работы с постами
   - `src/pages/AccountPage.tsx` - пример профиля
   - `src/components/PostCard.tsx` - компонент поста
   - `src/components/Sidebar.tsx` - боковая навигация
