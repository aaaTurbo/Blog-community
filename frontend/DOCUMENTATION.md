# BlogCommunity - Документация

## Новые страницы и компоненты

### 🌐 Созданные страницы:

#### 1. **FeedPage** (`/`) - Лента подписок
- Главная страница для аутентифицированных пользователей
- Отображает посты от людей, на которых подписан пользователь
- Функции:
  - Просмотр постов с реакциями
  - Система лайков (👍, ❤️, 😂, 😮, 😢, 😠)
  - Просмотр комментариев
  - Добавление новых комментариев
  - Реакции на комментарии

#### 2. **AccountPage** (`/account`) - Профиль пользователя
- Страница профиля текущего пользователя
- Содержит:
  - Аватар и информацию о пользователе
  - Статистика (посты, подписчики, подписки)
  - Две вкладки: "Посты" и "Информация"
  - На вкладке "Информация":
    - Описание (bio)
    - Местоположение
    - Контактная информация
    - Навыки (badge компоненты)
    - Дата присоединения

#### 3. **AboutPage** (`/about`) - О приложении
- Информация о платформе
- Список функций
- Стек технологий
- Контактная информация

### 🧩 Созданные компоненты:

#### **PostCard** (`src/components/PostCard.tsx`)
- Компонент карточки поста
- Отображает:
  - Информацию об авторе (аватар, имя, дата)
  - Содержание поста
  - Изображение (если есть)
  - Реакции и их количество
  - Кнопки действий (Like, Comment, Share)
  - Секцию комментариев (раскрывается при нажатии)

#### **CommentSection** (`src/components/CommentSection.tsx`)
- Компонент для управления комментариями
- Функции:
  - Добавление новых комментариев
  - Список комментариев с информацией об авторе
  - Реакции на комментарии
  - Отображение количества реакций

#### **Sidebar** (`src/components/Sidebar.tsx`)
- Боковая панель навигации в виде Sheet
- Содержит:
  - Кнопку меню (фиксированная в левом верхнем углу)
  - Навигацию по страницам:
    - Лента (/)
    - Мой профиль (/account)
    - О приложении (/about)
  - Переключатель темы (светлая/тёмная)
  - Кнопку выхода (logout)

#### **LoadingSpinner** (`src/components/LoadingSpinner.tsx`)
- Полноэкранный спиннер при загрузке страниц
- Красивый дизайн с:
  - Крупной иконкой загрузки (64px)
  - Текстом "Загрузка..."
  - Размытым фоном (backdrop-blur)
  - Фиксированным позиционированием
  - Темным полупрозрачным оверлеем (background/80)

### 📊 Созданные типы:

#### **PostTypes.ts** (`src/types/PostTypes.ts`)
```typescript
- Reaction - информация о реакции
- Comment - структура комментария с реакциями
- Post - полная структура поста
- UserProfile - информация о профиле пользователя
```

## 🎨 Стилизация

Все компоненты используют:
- **Tailwind CSS** для стилей
- **Radix UI** для базовых компонентов
- **Lucide Icons** для иконок
- Поддержка светлой/тёмной темы

## 🔒 Безопасность

- Все страницы (кроме login/register) защищены через ProtectedLayout
- Проверка наличия токена в authStore
- Автоматический логаут при 401 ошибке

## 📝 Mock Data

В данный момент все данные на страницах используют mock данные для демонстрации. Для интеграции с API:

1. Добавьте методы в `src/api/requests.ts`
2. Используйте их в компонентах вместо mock данных
3. Обновите состояние через useState/useEffect
