## ✅ Завершено: Добавлен красивый LoadingSpinner

### 📦 Что было создано:

**Новый компонент:**
- ✨ `LoadingSpinner.tsx` - полноэкранный спиннер при загрузке

**Характеристики LoadingSpinner:**
```typescript
// Размер иконки: 64px (крупная, хорошо видна!)
// Текст: "Загрузка..."
// Дизайн:
// - Фиксированный на весь экран (fixed inset-0)
// - Темный полупрозрачный фон (background/80)
// - Размытие заднего плана (backdrop-blur-sm)
// - Иконка крутится (animate-spin)
// - Цвет иконки совпадает с primary темой
```

### 🔄 Обновлено:

1. **Routes.tsx** - все маршруты теперь используют LoadingSpinner вместо старого SpinnerBadge
   - /login
   - /register
   - / (FeedPage)
   - /account (AccountPage)
   - /about (AboutPage)

2. **FeedPage.tsx** - замена SpinnerBadge на LoadingSpinner в условной части

3. **AccountPage.tsx** - замена SpinnerBadge на LoadingSpinner в условной части
